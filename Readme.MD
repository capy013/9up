# 9UP · 派對出題機 (offline)

一個**完全離線**嘅 9UP 出題 web app，配合實體卡牌喺聚會面對面玩。手機只負責出題、顯示提示、俾老實人偷睇答案、指認同開估；角色分派全靠你副實體牌。

> 冇 online、冇登入、冇配對、冇分數、冇局數管理 —— 一部手機圍住玩就得。

## 特點

- 📱 **一機走天涯** — 大按鈕、大字，啱傳嚟傳去
- 🎯 **開波選角** — 開始前轉手指指定現場邊個做諗樣、邊個做老實人
- 🎚️ **三個難度** — 輕鬆 / 中等 / 地獄
- 🤫 **老實人偷睇** — 兩種模式：
  - **撳實先睇**：撳實粒掣先睇到，放手即刻收埋
  - **限時睇**：閘門顯示你有幾多秒，㩒「開始睇」先倒數；夠鐘成格灰晒 show「夠鐘，準備開始」，唔畀再睇（限時秒數用滑桿揀 5–60 秒）
- 👉 **指認** — 由諗樣（負責猜嗰個）轉手指指住佢覺得最亂up嘅人
- 🔒 **滑動開估** — 雙重防手滑，揭曉真答案＋高亮返三個方向邊個係真
- ⚙️ **設定** — 睇答案模式、限時秒數、螢幕長開、震動回饋（記喺本機）
- 🌐 **零網絡** — 打開就用，可直接 host 喺 GitHub Pages

## 遊戲流程

開波選角（轉手指指諗樣＋老實人）→ 揀難度 → 睇題目＋三個方向 → 老實人睇答案（撳實／限時）→ 現場開估傾偈 → 諗樣指認 → 滑動開估 → 睇結果（答案＋三方向）→ 下一題


## 題庫

題目由 `data/questions.json` 載入（app 開場 `fetch`）。**全部題目都係經查證嘅真實冷知識**（跟 9UPPER 出題精神：真實冷門名詞 + 估唔到嘅真身）。

> ⚠️ 用 `file://` 直接開會被瀏覽器擋 `fetch`，app 會顯示提示並暫用一條示例題。要完整題庫，請用網頁伺服器開（`python3 -m http.server` 或 GitHub Pages）。

### JSON 格式

```json
{
  "version": 1,
  "questions": [
    {
      "id": 1,
      "word": "伊頓混亂",
      "answer": "三層書面語答案（真實定義 → 背景來源 → 生動收尾），約 60–150 字。",
      "hint1": "甜品",
      "hint2": "天氣現象",
      "hint3": "歷史事件",
      "correctHintIndex": 1,
      "category": "food"
    }
  ]
}
```

- `word`：真實冷門名詞（題面）
- `answer`：三層結構書面語解釋
- `hint1/2/3` + `correctHintIndex`（1-based）：供「有提示」模式，一真兩假
- `category`：分類（可選）

自己加題只需喺 `questions` 陣列尾加一條，`id` 唔好重複。

## 兩個遊戲模式

每次出題前揀：

- **冇提示**：淨係顯示古怪詞語，大家直接亂噏（最貼近原版）
- **有提示**：詞語 + 三個方向（一真兩假），諗樣有線索

一份 JSON 同時餵到兩個模式。
